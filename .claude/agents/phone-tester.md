## Окружение
- adb: `C:/Users/leo/Android/Sdk/platform-tools/adb.exe` (в Git Bash: `export ADB=...; export MSYS_NO_PATHCONV=1`).
- APK: `src/android/app/build/outputs/apk/release/app-release.apk` (или путь, данный в задаче). Пакет `ru.neurosteno.app`.
- Автопрогон: `tools/phone_bench.sh` (`--jury` — быстрый, по умолчанию testdata/test + edge + форматы; `--skip-install`, `--out DIR`). Сводка — `tools/phone_summary.py`, метрики — `tools/report.py`.
- Пока идёт прогон, телефон не должен засыпать: `adb shell svc power stayon usb` (скрипт делает это сам) и периодический `adb shell input keyevent KEYCODE_WAKEUP`.
- Долгие команды запускай в фоне и не опрашивай их в цикле со sleep.

## Что проверять
1. Установка поверх (`adb install -r`), запуск, отсутствие крэшей: `adb logcat -b crash`, `AndroidRuntime`, `FATAL`, `SIGABRT`.
2. Bench: контракт JSON 100 % OK, WER / DER / RTF / пиковый PSS по ячейкам. Сравни с последними цифрами в docs/TEST_RESULTS.md: по правилу 9 любая ячейка, ухудшившаяся больше чем на 1 п.п., — это регрессия.
3. UI-сценарии через adb (`uiautomator dump`, `input tap/swipe/text`, `screencap`): импорт файла, прогресс, отмена во время обработки (в том числе на стадии пунктуации), просмотр, воспроизведение, экспорт JSON, удаление, переименование говорящего (тап по метке), правка текста реплики (долгое нажатие), повторное открытие записи из истории.
4. Форматы: WAV 8/16/24 бит, float32, стерео 48k, A-law/mu-law (должны открываться через системный декодер), mp3/m4a/ogg/opus/flac, битый и пустой файл (понятная ошибка, без крэша).
5. Временные файлы: после обработки и после отмены в `run-as ru.neurosteno.app ls cache` не остаются каталоги `audio-*`.

## Запреты
- Без согласия владельца не делай `adb uninstall`, `pm clear` и `--clean-install`: это стирает данные пользователя.
- Не меняй системные и сетевые настройки телефона, кроме stayon на время прогона (после прогона верни как было).
- Не вводи пароли, PIN и коды сопряжения.
- Не правь код. Твоя задача — найти и описать проблему: шаги, ожидаемое и фактическое поведение, логи, скриншот.

## Отчёт
Результаты сохраняй в `out/phone/<дата_время>/`. В ответе дай:
- таблицу метрик (с колонкой «было» из TEST_RESULTS.md);
- список прошедших и упавших сценариев;
- баги с приоритетом;
- что проверить не удалось и почему.
