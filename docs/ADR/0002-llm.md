# ADR-0002: Локальная LLM — llama.cpp + Qwen2.5-0.5B-Instruct Q4_K_M

Статус: принято, 2026-11-06.

## Контекст
ТЗ (слайд 9) требует локальную LLM. Правило 3 AGENTS.md: LLM не меняет слова, спикеров, тайминги, число и порядок реплик — только регистр и пунктуацию. Целевой телефон 4–6 ГБ RAM.

## Решение
- Рантайм: **llama.cpp** (MIT), исходники клонируются в `src/android/engine-llm/src/main/cpp/llama.cpp` (в git не хранится; коммит `669204ee2b9004845b34f26466a91d003edc98aa`, 2026-11-06).
  Сборка статически в одну `libneurollm.so` через NDK 27 / CMake 3.22: `GGML_NATIVE=OFF`, `GGML_OPENMP=OFF`, `GGML_LLAMAFILE=OFF`, `LLAMA_OPENSSL=OFF`, без tools/examples/server/tests; для arm64 `GGML_CPU_ARM_ARCH=armv8.2-a+dotprod+fp16`. Сетевого кода нет.
- Модель: **Qwen2.5-0.5B-Instruct Q4_K_M** (491 МБ, Apache-2.0) — влезает в 4 ГБ телефон вместе с остальным конвейером, т.к. LLM запускается после выгрузки ASR и диаризации. A/B-кандидат: Qwen3-0.6B Q4_K_M.
- JNI: `load(path, nCtx=2048, nThreads≤4)`, `complete(system, user, maxTokens, stopper)` — chat template из метаданных GGUF, greedy (детерминированно), отмена между токенами, ответ возвращается байтами UTF-8; `free`.
- Модель лежит в assets (noCompress) и один раз копируется в `filesDir` (llama.cpp открывает файл по пути). Цена — ~0.5 ГБ на диске.
- `GuardedEditor` (core): по одной реплике, промпт «только пунктуация и регистр», ответ проходит `WordGuard` (нормализованные слова до/после совпадают), иначе — текст ASR. Бюджет на файл — `llmBudgetFraction × длительность` (стартово 0.3), по исчерпании остаток реплик не правится.

## Последствия
- ASR GigaAM v3 e2e уже выдаёт пунктуацию и регистр, поэтому вклад LLM в WER нулевой по построению (WER считается без пунктуации, а слова LLM менять не может). LLM влияет на читаемость и время (RTF). Включение по умолчанию — только если RTF-вклад на телефоне приемлем [Проверить на телефоне].
- Fallback: модель не загрузилась / OOM / таймаут → текст ASR, предупреждение в UI.

## Риски
- RTF-вклад на телефоне [Проверить]; при превышении — уменьшить бюджет или батчить несколько реплик в один промпт.
- Пиковая RAM: mmap модели ~0.5 ГБ + KV-кэш 2048 ток. [Проверить].
