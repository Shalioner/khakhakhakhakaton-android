## Установка и ограничения сборки

- Android 9+ (minSdk 28), arm64-v8a; размер APK около 1.1 ГБ. Все модели находятся внутри APK, интернет приложению не нужен.
- Новый Mac APK использует другой ключ подписи, чем опубликованная v0.1.0, поэтому поверх неё не устанавливается. Сначала экспортировать нужные расшифровки и отдельно сохранить доступные исходные аудиофайлы. Самостоятельное удаление приложения стирает локальную историю и внутренние аудиофайлы. Экспорт JSON сохраняет текст, но не аудио и не всю историю приложения.
- На физическом телефоне этот APK пока не проверен. Исторические Pixel-замеры в `TEST_RESULTS.md`, включая раздел v0.2.0, получены на другом APK и не подтверждают работоспособность или производительность новой Mac-сборки.
- Видеозаписи сняты на v0.1.0. Они не демонстрируют новые функции v0.2.0 и не являются проверкой новой Mac-сборки.
- Сохраняются ограничения по похожим голосам, одновременной речи, редким форматам и точности протокола маленькой LLM; подробно — [LIMITATIONS.md](LIMITATIONS.md).

## Среда и целостность APK

Сборка: macOS 15.7.9 (Apple Silicon), Temurin JDK 21.0.13+9, Gradle 8.11.1, Android Gradle Plugin 8.7.3, NDK 27.2.12479018, CMake 3.22.1. llama.cpp закреплён на `669204ee2b9004845b34f26466a91d003edc98aa`, sherpa-onnx — 2.0.1. Логика приложения относительно `3c91bf7` не менялась; изменения исходников пакета касаются документации и исполняемого флага `gradlew`. Запуск `./gradlew --version` с JDK 21 проверен.

Размер APK — 1 173 016 992 байта. ZIP проверен на целостность; в APK есть 21 файл моделей. Веса и остальные файлы побайтно совпадают с опубликованной v0.1.0; у `nemotron/NOTICE` изменились только CRLF/LF, текст атрибуции сохранён. Файлы ONNX, GGUF и TXT не сжаты. SHA-256 APK также подтверждён сервером GitHub после загрузки.

SHA-256 сертификата новой сборки: `cc53fe7ed14cfb99e496e4e3f986f1d8baf59f587c1db9878659601cc7fd4d53`. Сертификат v0.1.0: `6cc8f5bd8106a6dfd6036a9d00025fed2a5a5ec40410b60d24a81205818de62f`. Отличие подписей подтверждено `apksigner verify --print-certs`.

## Контрольный прогон новой сборки

Android 15 (API 35), arm64-эмулятор, два потока, Nemotron включён, авиарежим. Синтетическая русская запись (голос Milena, macOS `say`) длительностью 11 639 мс: одна реплика, один говорящий; текст полностью совпал с исходной фразой. JSON сохранён `BenchActivity` и прошёл проверку контракта с длительностью исходного файла. Крэшей процесса приложения в этом прогоне не зафиксировано.

Обработка заняла 59 783 мс (RTF 5.1364). Это время конкретного эмулятора под нагрузкой, **не замер телефона и не сравнение с историческими Pixel-результатами**. Один синтетический файл не заменяет тестовую матрицу и оценку качества на живой речи.

Обычная установка и запуск проверены. Первичная передача сырого `file://` из ADB получила EACCES; проверочный конвейер затем запускался с тестовыми данными в каталоге приложения. Root ADB использовался только в изолированном эмуляторе для размещения и извлечения этих данных; само приложение работало под обычным UID `u0_a207`. Нормальный импорт через SAF и UI-экспорт остаются отдельными непроверенными сценариями.

В архиве материалов, каталог `release-checks/`: сводка `verification.json`, `runtime-result.json`, SHA-256 файлов моделей, сведения о подписи и разрешениях, тестовый WAV, эталонная фраза, распознанный JSON и тайминги. Видеодемонстрации сохранены прежними по решению владельца.
