# Задание: «Нейро-стенографист» (Nuclear IT Hack, ноябрь 2026)

Источник: презентация организаторов, слайды 8–22.

## Формулировка (сл. 8)
Android-приложение, которое **локально** преобразует аудиозаписи разговоров в текст, автоматически определяя говорящих и разделяя их реплики. Формирует структурированную расшифровку с участниками и временными метками. Результат доступен для просмотра в приложении и экспорта в файл. Все этапы — на устройстве.

## Обязательные требования (сл. 9)
- Android OS; **локальная LLM**;
- импорт аудио из памяти устройства;
- речь → текст; автоматическая диаризация;
- временные метки реплик; отображение расшифровки; экспорт в файл.

## Запрещено (сл. 10–11)
1. Передавать аудио внешним сервисам. 2. Облачные API для транскрибации/диаризации/текста. 3. Вычисления на удалённом сервере/ПК. 4. Подменять работу модели заранее подготовленной расшифровкой.
Основная задача — без интернета; все модели на устройстве к моменту проверки. Готовые модели и библиотеки разрешены.

## Ввод/вывод (сл. 14–15)
Вход: аудиофайл из локального хранилища либо записанный в приложении.
Выход: JSON
```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

## Проверка (сл. 16)
Эксперты ставят APK, импортируют **три тестовые записи диалогов котиков**, запускают транскрибацию и диаризацию, экспортируют, сравнивают с эталоном: **WER** и **RTF**.

## Уровни (сл. 17–19)
- Базовый: APK, импорт, локальная LLM, ASR, диаризация, тайминги, просмотр и экспорт.
- Средний: предобработка, фильтрация пауз/неречи, устойчивые спикеры, пунктуация, прогресс, плеер с переходом к реплике.
- Ultra: шум, короткие реплики и перебивания, одновременная речь, разные тембры, экономия RAM, аппаратное ускорение, редактирование и повторная обработка фрагментов.

## Отчётность (сл. 20–21)
APK, исходники, инструкция, архитектура и модели, ограничения, результаты тестов, видео. Репозиторий по шаблону github.com/grigorevmp/hacathon_template.
