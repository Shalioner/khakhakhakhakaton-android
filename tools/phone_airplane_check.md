# Ручной чек-лист на телефоне (авиарежим) и сценарий «как жюри»

Дополняет автоматический прогон `tools/phone_bench.sh` (план и критерии — `docs/PHONE_TEST_PLAN.md`).
Время: ~20–25 мин. Нужны: секундомер, второй человек или видеозапись экрана (`adb shell screenrecord /sdcard/check.mp4`, до 3 мин на файл).

Подготовка на ПК:
```bash
tools/phone_bench.sh --manual-push      # 3 «жюри»-файла + mp3/opus + тишина + битый → /sdcard/Download/NeuroSteno
```
Файлы: `distinct_2spk_000.wav` (2 спикера, 2:01), `clean_2spk_001.wav` (2 спикера, похожие голоса, 1:32),
`noisy_3spk_000.wav` (3 спикера, шум, 3:04), `distinct_2spk_000__mp3_44k_st.mp3`, `distinct_2spk_000__opus_48k_mono.opus`,
`edge_silence_10s.wav`, `edge_broken.wav`.

Записывать в таблицу результатов (внизу): ✅/❌, время, фото/скрин при ❌, текст ошибки.

## B. Сценарий «как жюри» (3 файла подряд)

Цель — увидеть то, что увидит жюри: время по секундомеру vs RTF из приложения и качество экспорта.

1. Чистая установка (п. 2), авиарежим (п. 1), телефон остыл, заряд ≥ 50 %.
2. Для каждого файла по очереди — `distinct_2spk_000.wav`, `clean_2spk_001.wav`, `noisy_3spk_000.wav`:
   1. «Новый» (для первого — сразу) → «Выбрать аудиофайл» → файл. **Старт секундомера — в момент тапа по файлу.**
   2. **Стоп — когда появилась расшифровка.** Записать T_секундомер.
   3. Записать RTF и «обработка мм:сс» из шапки результата, число говорящих.
   4. «Экспорт JSON» → Загрузки.
3. На ПК: `tools/phone_bench.sh --manual-collect` → валидатор для каждого JSON + `report.md` (WER/DER/границы).
4. Сравнить:
   - RTF_секундомер = T_секундомер / длительность (121.0 / 91.8 / 183.8 с) vs RTF из приложения. Разница > 10 % —
     в приложении не учтено время до старта сервиса/копирование LLM/отрисовка; жюри будет считать по своему секундомеру.
   - Первый файл vs второй/третий (холодный старт).
   - WER/DER экспорта vs `report_main.md` автоматического прогона тех же файлов: должны совпадать (одна и та же обработка).
     Расхождение = недетерминизм (потоки, LLM) — записать.

| файл | длит., с | T_секундомер, с | RTF_секундомер | RTF в приложении | «обработка» | спикеров (эталон) | WER, % | DER, % | валидатор |
|---|---|---|---|---|---|---|---|---|---|
| distinct_2spk_000 | 121.0 | | | | | 2 | | | |
| clean_2spk_001 | 91.8 | | | | | 2 | | | |
| noisy_3spk_000 | 183.8 | | | | | 3 | | | |
