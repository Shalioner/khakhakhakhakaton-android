# Материалы демонстрации

| материал | статус |
|---|---|
| Видео работы приложения на телефоне (импорт → обработка → расшифровка → воспроизведение → экспорт JSON, авиарежим) | ⏳ будет снято на телефоне, сценарий ниже |
| Пример экспортированного JSON | [example_transcript.json](example_transcript.json) — результат конвейера на синтетическом диалоге `testdata/test/distinct_2spk_000` |
| Скриншоты экранов | ⏳ после прогона на телефоне |

## Сценарий видео (≈2 мин)
1. Включить авиарежим, показать, что сети нет.
2. Открыть «Нейро-стенографист» → «Выбрать аудиофайл» → запись диалога.
3. Экран прогресса: этапы (декодирование, поиск речи, распознавание, говорящие, сборка, пунктуация), отмена доступна.
4. Расшифровка: цвета и номера говорящих, время реплик; тап по реплике — воспроизведение с этого места.
5. «Экспорт JSON» → сохранить в «Загрузки», открыть файл и показать структуру `transcript[]`.
6. «Протокол» — краткий протокол от локальной LLM.
7. «Записать с микрофона» → короткая фраза → расшифровка.

Видео в git не хранится (`.gitignore`: `artifacts/demo/*.mp4`) — ссылка будет добавлена сюда.
