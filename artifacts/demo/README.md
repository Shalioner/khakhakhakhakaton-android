## Что в видео (запись экрана со звуком устройства, 2026-11-07)
1. Шторка: включён авиарежим, Wi-Fi выключен — сети нет.
2. Чистая установка приложения: пустой список «Записи».
3. «Открыть файл» → системный выбор файла → `distinct_2spk_000.wav` (2:01, синтетический диалог двух голосов).
4. Обработка: кольцо общего прогресса, стадии (декодирование, поиск речи, распознавание ‖ определение говорящих, сборка реплик, пунктуация) — 32 с на 2:01 аудио.
5. Расшифровка: цвета говорящих, время реплик; тап по реплике — воспроизведение с этого места, подсветка текущей реплики.
6. «Протокол»: участники и доля речи, длительность, ключевые слова.
7. «Экспорт JSON» → сохранение в «Загрузки».
8. Возврат к списку: запись сохранена в истории.

Экспортированный в этом прогоне JSON проверен: контракт OK (`tools/validate_json.py`), WER 0.85 %, cpWER 0.85 % против эталона `testdata/test/distinct_2spk_000.json`.

Запись с микрофона показана во втором видео `demo_mic_v0.2.0.mp4`.
